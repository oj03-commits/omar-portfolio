# Omar John U. Flores – Personal Portfolio

React + Vite personal website (Home, Education, About, Skills, Contact).

## Run on your computer
```bash
npm install
npm run dev
```

## Put it on GitHub (live link with all designs)
```bash
git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/oj03-commits/YOUR-REPO-NAME.git
git push -u origin main
```
Then on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Wait about 1–2 minutes (check the **Actions** tab). Your link will be:
`https://oj03-commits.github.io/YOUR-REPO-NAME/`

## Edit your info
Open `src/App.jsx` and change the data at the top (email, LinkedIn, strand, etc.).
Images are in `src/assets/`.
